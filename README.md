# 3D Gradient Descent Visualization

A Python project that visualizes the **Gradient Descent optimization algorithm on a 3D terrain surface** using NumPy and Matplotlib.

The project demonstrates how gradient-based optimization can be used to explore downhill paths on an elevation map. Starting from a randomly selected point, the algorithm follows the negative gradient and visualizes its trajectory across the terrain.

## Overview

Gradient Descent is an iterative optimization algorithm used to find local minima of a function. At each iteration, the current position is updated in the direction opposite to the gradient.

In this project, the elevation of a terrain represents the objective function. The algorithm calculates the terrain gradients, updates its position, and plots the resulting path on a three-dimensional surface.

## Features

- **3D Terrain Rendering** — Visualize an elevation map as a shaded 3D surface.
- **Random Initialization** — Select a random starting point from the terrain grid.
- **Gradient Calculation** — Compute gradients along the row and column directions using NumPy.
- **Iterative Optimization** — Move downhill using the negative gradient.
- **Boundary Constraints** — Keep the position within the terrain boundaries.
- **Path Visualization** — Display the optimization trajectory with clear starting and ending markers.
- **Configurable Parameters** — Experiment with different learning rates and iteration counts.

## Mathematical Background

The Gradient Descent update rule is:

\[
\mathbf{p}_{t+1} = \mathbf{p}_t - \alpha \nabla z(\mathbf{p}_t)
\]

Where:

- \(\mathbf{p}_t\) is the current position.
- \(\alpha\) is the learning rate.
- \(z(\mathbf{p})\) represents the elevation function.
- \(\nabla z(\mathbf{p}_t)\) is the gradient at the current position.

The negative gradient indicates the direction of steepest local decrease in elevation.

### Algorithm Workflow

1. Load a sample Digital Elevation Model (DEM).
2. Extract a smaller region of the terrain.
3. Randomly select an initial point.
4. Calculate the elevation gradients.
5. Update the position in the negative gradient direction.
6. Constrain the position to the valid grid boundaries.
7. Record the trajectory over the specified number of iterations.
8. Render the terrain and optimization path in 3D.

You can adjust the main hyperparameters in the script:

```python

epoch = 2000
```

| Parameter | Description |
|---|---|
| `lr` | Learning rate controlling the update step size |
| `epoch` | Number of optimization iterations |

A learning rate that is too large may cause unstable updates, while a very small learning rate may result in slow progress.

## Limitations

- The optimization operates on a discrete elevation grid.
- Grid indices are used for position updates rather than continuous physical coordinates.
- Converting updated positions to integer indices can cause repeated positions and limit movement.
- The algorithm is not guaranteed to find the global minimum.
- The final point may not represent a true converged minimum, particularly when the trajectory reaches a boundary.
